# A Generative AI and Security Tool Based Automated Penetration Testing Framework — 论文分析

## 论文信息

- **标题**: A Generative AI and Security Tool Based Automated Penetration Testing Framework（基于生成式AI与安全工具的自动化渗透测试框架）
- **作者**: BRAC University（孟加拉国BRAC大学）学生团队，学号：21201158, 21201169, 21301568, 21301237, 21201155（计算机科学与工程系）
- **所属**: BRAC University, Department of Computer Science and Engineering
- **发表**: 本科毕业设计论文（2025-2026）

## 一、核心产出

1. **生成式AI驱动的自动化渗透测试框架**: 提出一个基于GPT-5等生成式AI模型与企业级安全工具（Nmap、Metasploit、Burp Suite、Sqlmap等）集成的新型自动化渗透测试框架，实现从信息收集到漏洞利用的全流程自动化。

2. **CVSS RAG知识增强机制**: 引入基于检索增强生成（RAG）的CVSS（通用漏洞评分系统）知识库，使框架能够基于目标系统信息实时检索和参考最新的漏洞评分和利用信息，提升漏洞评估的准确性和时效性。

3. **模块化插件架构**: 设计模块化框架架构，将不同渗透测试阶段的功能封装为独立插件模块，支持灵活的工具集成和功能扩展。

4. **多阶段渗透工作流**: 实现信息收集→漏洞分析→漏洞利用→后渗透的标准化四阶段工作流，由GPT-5作为核心推理引擎驱动各阶段的策略决策。

## 二、框架架构设计

### 总体架构

框架采用分层模块化架构，以GPT-5作为核心推理引擎，统一协调各安全工具的调用和渗透策略的制定：

**第一层：用户接口层（User Interface Layer）**
- 提供命令行界面（CLI）和可选的Web界面
- 接收用户输入的目标系统和渗透目标
- 展示实时渗透进度、发现的漏洞和利用结果

**第二层：核心引擎层（Core Engine Layer）**
- **任务规划器（Task Planner）**: 基于GPT-5的推理能力制定高层次的渗透策略和步骤规划
- **状态管理器（State Manager）**: 维护渗透过程中的全局状态（已收集信息、已发现漏洞、已获取凭证等）
- **决策模块（Decision Module）**: 基于当前状态和后续目标，决策下一步应执行的操作
- **RAG检索器（RAG Retriever）**: 从CVSS知识库中检索与目标系统相关的漏洞信息和利用建议

**第三层：工具集成层（Tool Integration Layer）**
- 通过标准化API接口集成多种安全工具：
  - **Nmap**: 网络扫描与服务发现
  - **Metasploit Framework**: 漏洞利用与payload生成
  - **Burp Suite**: Web应用安全测试
  - **Sqlmap**: SQL注入自动化检测与利用
  - **Nikto**: Web服务器扫描
  - **Gobuster**: 目录/子域名爆破
  - **Hydra**: 在线密码暴力破解
- 工具调用结果以结构化格式返回给核心引擎层进行分析

**第四层：知识库层（Knowledge Base Layer）**
- **CVSS漏洞知识库**: 包含CVE漏洞详情、CVSS评分、利用方法等
- **攻击模板库**: 常见攻击场景的预设工作流模板
- **报告模板库**: 测试报告自动生成模板

### RAG增强的CVSS知识库

框架的核心创新之一是CVSS RAG机制：
1. 在信息收集阶段，框架自动识别目标系统的操作系统、服务版本等指纹信息
2. 基于这些指纹信息，RAG检索器在CVSS知识库中检索相关CVE漏洞
3. 检索结果包括漏洞描述、CVSS评分、影响版本和已知利用方法
4. GPT-5基于检索结果进行漏洞分析和利用策略规划
5. 利用完成后，框架自动生成包含CVSS评分的漏洞评估报告

### GPT-5核心推理引擎

GPT-5作为框架的核心推理引擎，承担以下关键职责：
- **任务理解**: 将用户的高级目标（如"渗透测试目标IP X.X.X.X"）转化为具体的操作步骤
- **工具选择**: 基于当前阶段和目标，选择最合适的工具和参数
- **结果分析**: 解析工具输出，提取关键信息，识别漏洞
- **策略调整**: 根据渗透进度动态调整策略，如发现新端口后切换攻击方向
- **报告生成**: 基于全部渗透过程自动生成格式化的安全测试报告

## 三、实验设计

- **实验环境**: 在受控的虚拟化环境中搭建多台靶机，覆盖常见的Web应用漏洞和操作系统漏洞
- **评估任务**: 从信息收集到获取目标系统控制权的完整渗透测试流程
- **对比基线**: 传统半自动化渗透测试流程与手动渗透测试进行对比
- **评估指标**:
  - 漏洞发现率
  - 漏洞利用成功率
  - 渗透全流程完成时间
  - 工具参数准确率
  - 误报率（假阳性）
  - 漏报率（假阴性）
- **基础模型**: GPT-5（作为主推理引擎）

## 四、实验结果

### 自动化效果

框架在受控环境中展示了从初始目标识别到最终权限获取的端到端自动化能力：

- **信息收集阶段**: 自动执行多轮Nmap扫描（端口扫描、服务版本检测、OS指纹识别），结合Gobuster进行目录枚举，信息收集覆盖率接近手动渗透水平
- **漏洞分析阶段**: 基于CVSS RAG检索结果，GPT-5能够针对目标系统识别相关的高危漏洞，并根据CVSS评分优先处理高风险漏洞
- **漏洞利用阶段**: 自动配置Metasploit模块参数（RHOSTS、RPORT、PAYLOAD等），执行漏洞利用并获取初始访问权限
- **后渗透阶段**: 自动进行权限提升、信息收集和横向移动

### LLM贡献分析

GPT-5在框架中的核心价值体现在：
- **上下文理解**: 能够理解复杂的渗透场景和多步攻击链的依赖关系
- **参数生成**: 为安全工具自动生成格式正确的复杂命令行参数，减少了手动配置工作量
- **结果综合**: 能够从大量工具输出中提取关键发现，避免了传统自动化工具的信息过载问题
- **策略调整**: 在攻击路径受阻时能够基于上下文理解调整策略

### 局限性发现

- 对需要人工判断的复杂场景（如业务逻辑漏洞、条件竞争等）处理能力有限
- 安全工具的输出格式变化可能导致LLM解析失败
- 在长周期渗透任务中可能出现"注意力漂移"——偏离当前目标
- CVSS RAG检索的时效性依赖知识库的更新频率

## 五、讨论与局限

**生成式AI在渗透测试中的角色定位**: 论文认为GPT-5等生成式AI不应替代渗透测试人员，而是作为增强工具协助安全专家提高工作效率。框架最适合的场景包括常规漏洞扫描和利用、报告自动生成、知识辅助决策等，而非替代人类在需要创造性和深度分析的高级渗透场景中的作用。

**CVSS RAG的价值与局限**: RAG机制的引入有效缓解了LLM知识截止日期带来的时效性问题，使框架能够检索和参考最新漏洞信息。但CVSS知识库的完整性和更新频率直接影响检索质量，且CVSS评分本身并不完全反映漏洞的可利用性。

**本科毕业设计的现实考量**: 作为BRAC大学的本科毕业设计，论文在实验规模和系统成熟度上存在局限。实验环境覆盖的漏洞类型和靶机数量有限，框架在真实生产环境中的表现尚需进一步验证。

**局限**: 实验环境规模有限；未在有防御机制（WAF、IDS/IPS等）的环境中进行测试；对不同LLM模型的对比研究不够深入；框架的鲁棒性和错误恢复机制尚不完善；未涉及社会工程学等非技术攻击向量。

## 六、总结

该论文提出了一个基于GPT-5等生成式AI模型与企业级安全工具集成的自动化渗透测试框架，采用分层模块化架构实现信息收集、漏洞分析、漏洞利用和后渗透的全流程自动化。框架的核心创新在于引入CVSS RAG知识增强机制，使LLM能够实时检索最新漏洞信息进行决策。实验结果表明，GPT-5在上下文理解、参数生成和结果综合上展现了显著优势，能够有效驱动多阶段渗透工作流。虽然作为本科毕业设计在系统成熟度和实验规模上存在局限，但该工作展示了生成式AI在自动化安全测试中的潜力，为低成本、高效率的安全评估工具开发提供了有意义的探索方向。
